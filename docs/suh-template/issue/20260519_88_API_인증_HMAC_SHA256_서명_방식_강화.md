# 🚀[기능개선][보안] API 인증 방식 HMAC-SHA256 + Timestamp 서명 방식으로 강화

- 라벨: 작업전
- 담당자: Cassiiopeia

---

📝 현재 문제점
---

- 프론트엔드와 백엔드 간 API 인증이 고정 키 방식으로 구현되어 키 탈취 시 재사용이 가능한 보안 취약점 존재

🛠️ 해결 방안 / 제안 기능
---

- HMAC-SHA256 + Timestamp 방식으로 API 인증 강화
- 요청마다 X-Timestamp(현재 시각) + X-Signature(HMAC-SHA256 서명) 헤더를 포함
- 백엔드에서 타임스탬프 만료(±5분) 및 서명 일치 검증
- 서명 검증에 constant-time 비교 적용으로 timing attack 방지
- 시크릿 키를 환경변수(SECRET_KEY / VITE_SECRET_KEY)로 관리

⚙️ 작업 내용
---

- 백엔드: 고정 API Key 미들웨어 제거 → HMAC 서명 검증 미들웨어로 교체
- 프론트엔드: 모든 API 요청에 HMAC 서명 헤더 자동 포함
- 환경변수 키 이름 변경 (API_KEY → SECRET_KEY)
