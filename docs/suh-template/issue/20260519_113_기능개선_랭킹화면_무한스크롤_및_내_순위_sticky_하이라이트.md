# 🚀[기능개선][랭킹] 랭킹 화면 무한스크롤 및 내 순위 sticky 하이라이트

- **라벨**: 작업전
- **담당자**: Cassiiopeia

---

📝 현재 문제점
---

- 랭킹 화면이 `getRanking(20)` 고정으로 상위 20개만 표시되며, 더 많은 데이터를 볼 방법이 없음
- `App.tsx`에서 `RankingScreen`으로 `nickname` prop을 전달하지 않아 내 순위를 식별할 수 없음
- 내 순위가 어디에 있는지 알 수 없어 상대적인 위치 파악이 불가

🛠️ 해결 방안 / 제안 기능
---

- 무한스크롤 적용: 20개씩 페이지 단위로 추가 로드 (스크롤 하단 도달 시 자동 로드)
- `App.tsx`에서 `nickname` prop을 `RankingScreen`에 전달
- 내 닉네임 행 IntersectionObserver 기반 sticky 처리:
  - 내 행이 뷰포트 밖 → 테이블 컨테이너 하단에 sticky 고정 (보라색 하이라이트)
  - 내 행이 뷰포트 안 → sticky 숨김, 인라인 하이라이트만 표시
  - 비로그인(닉네임 없음) 상태에서는 sticky 없음

⚙️ 작업 내용
---

- `RankingScreen.tsx`: 무한스크롤 구현 (`useRef` + `IntersectionObserver`), nickname prop 추가, sticky 내 행 컴포넌트 추가
- `App.tsx`: `RankingScreen`에 `nickname` prop 전달
- `playerService.ts`: `getRanking(limit, offset)` offset 파라미터 추가
- 백엔드 `/ranking` API: `offset` 쿼리 파라미터 지원 확인 또는 추가
