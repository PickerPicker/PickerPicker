🗒️ 설명
---

게임 플레이 중 note가 타격점에 도착하기 전에 키를 누르면 해당 note가 MISS 판정 후 `pendingIndex`가 즉시 다음 note로 이동한다. 화면에는 아직 그 note가 보이는데 다음 note를 노려야 하는 상황이 발생해 플레이 흐름이 끊기고 혼란이 생긴다.

- 리듬게임 표준 동작은 GOOD_WINDOW 밖에서 잘못 친 입력은 패널티만 적용하고 note는 살려둔다.
- 현재 구현은 어떤 시점에 키를 눌러도 무조건 다음 note로 advance한다.

🔄 재현 방법
---

1. 게임 화면 진입 후 스테이지 시작
2. 첫 번째 note가 화면 오른쪽에서 등장하자마자(아직 타격점 도달 전, GOOD_WINDOW 밖) 키 입력
3. MISS 판정 + 사운드 발생
4. 화면에 첫 번째 note는 여전히 흘러가고 있으나 시스템 내부 `pendingIndex`는 두 번째 note로 이동
5. 사용자가 화면상 첫 번째 note의 도착 시점에 맞춰 다시 키를 누르면 두 번째 note로 평가됨 → 시각·판정 불일치

✅ 예상 동작
---

- GOOD_WINDOW(±250ms) **안**에서 입력: 현재처럼 PERFECT/GOOD/MISS 판정 후 advance
- GOOD_WINDOW **밖**에서 입력 (조기 입력): MISS 사운드 + 게이지 감소만 적용, `pendingIndex`는 그대로 유지 → note가 도착하면 다시 칠 기회 부여
- 자동 MISS (도착 후 시간 경과): 현재대로 advance 유지
