📝 현재 문제점
---

- 브라우저 자동재생 정책(Autoplay Policy)으로 인해 사이트 첫 진입 시 BGM이 재생되지 않음
- 사용자가 설정 화면의 볼륨 바를 직접 조작해야 BGM이 시작되는 문제
- 키보드 기반 게임임에도 불구하고 조작 키 안내가 없어 첫 방문자가 플레이 방법을 직관적으로 파악하기 어려움
- 관련 파일: `src/App.tsx`, `src/hooks/useAudio.ts`

🛠️ 해결 방안 / 제안 기능
---

- 사이트 첫 방문 시 Welcome 오버레이 모달을 표시
  - 환영 메시지 표시
  - 게임 키보드 조작법 안내 (예: 방향키, 스페이스바 등)
  - "클릭하여 시작" 형태로 사용자 인터랙션 유도
- 모달 클릭 시 닫히면서 BGM 자동 시작 (브라우저 Autoplay Policy 우회)
- `localStorage`로 첫 방문 여부 체크하여 재방문 시 모달 미표시

⚙️ 작업 내용
---

- `src/components/common/WelcomeModal.tsx` 신규 컴포넌트 생성
- `src/App.tsx`에서 첫 방문 여부 체크 및 모달 표시 로직 추가
- 모달 클릭 시 `audio.playStartBgm()` 호출하여 BGM 시작
- `localStorage` 키(`pickerpicker_welcome_seen`) 활용
