🗒️ 설명
---

`backend/src/core/seed.py`의 자동 시드가 **프로덕션 컨테이너에서 항상 실패**한다.

시드 데이터셋 경로가 프로젝트 루트 기준으로 잡혀 있다:

```python
# backend/src/core/seed.py:21
DATASET_PATH = Path(__file__).resolve().parents[3] / "docs" / "rhythm_stages_001_015.json"
```

그런데 백엔드 Docker 이미지는 `backend/` 하위만 복사한다 (`COPY src/`, `alembic.ini`, `alembic/`, `scripts/run_migrations.sh`). `docs/`가 이미지에 들어가지 않는다.

컨테이너에서는 파일이 `/app/src/core/seed.py`이므로 `parents[3]` = `/` 가 되어 `/docs/rhythm_stages_001_015.json`을 찾고, 당연히 없다.

```
WARNING src.core.seed: 시드 데이터셋 없음: /docs/rhythm_stages_001_015.json
```

### 현재 영향

현재 운영 DB에는 이미 단어가 들어 있어 `seed_words()`가 "이미 존재하면 스킵"으로 빠져나가므로 **당장 장애는 없다.** 다만 다음 상황에서 문제가 된다.

- 새 환경(스테이징/로컬 docker-compose)에 배포하면 단어 풀이 비어 게임을 시작할 수 없다
  (`/games/start`가 `insufficient_word_pool` 422 반환)
- DB를 초기화하거나 마이그레이션으로 재구축하면 복구되지 않는다

### 발견 경위

#158에서 CI에 pytest를 추가하며 확인했다. `test_seed.py` 2건이 컨테이너 안에서 실패했고(`assert 0 == 15`), 레포 전체를 마운트하면 통과한다. 즉 테스트는 통과하지만 **배포 이미지에서는 경로가 다르다.**

🔄 재현 방법
---

1. 빈 DB를 가리키도록 백엔드 컨테이너를 기동한다
2. 기동 로그에 `시드 데이터셋 없음: /docs/rhythm_stages_001_015.json` 경고가 뜬다
3. `POST /games/start` 호출 → `422 insufficient_word_pool`
4. 게임을 시작할 수 없다

또는 실행 중인 컨테이너에서 직접 확인:

```bash
docker exec pickerpicker-back ls /docs/rhythm_stages_001_015.json
# → No such file or directory
```

✅ 예상 동작
---

- 빈 DB로 기동해도 자동 시드가 동작해 단어 15개가 들어가야 한다
- 시드 데이터셋이 배포 이미지에 포함되어야 한다
- 시드에 실패하면 경고가 아니라 눈에 띄는 형태로 드러나야 한다 (새 환경에서 조용히 실패하면 원인 추적이 어렵다)

🛠️ 해결 방안
---

빌드 컨텍스트가 `./backend`라 `docs/`를 그대로 `COPY`할 수 없다. 아래 중 하나를 택한다.

1. **데이터셋을 backend 안으로 이동** (권장)
   `docs/rhythm_stages_001_015.json` → `backend/src/data/rhythm_stages_001_015.json` 으로 옮기고
   `seed.py` 경로를 패키지 상대 경로로 바꾼다. 설계 문서에서 참조하던 경로는 문서에서 갱신한다.
   Dockerfile은 이미 `COPY src/`를 하므로 추가 변경이 거의 없다.

2. **빌드 컨텍스트를 레포 루트로 변경**
   `PROJECT-PYTHON-CI.yaml` / `PROJECT-PYTHON-CICD.yaml`의 `context`를 `.`로 바꾸고
   Dockerfile 경로를 조정한다. 배포 워크플로우 구조를 건드리므로 리스크가 있다.

3. **경로 후보 탐색**
   `seed.py`가 여러 후보 경로를 순회하게 한다. 근본 해결은 아니고 "어디선가 찾아지길 기대"하는 방식이라 권장하지 않는다.

추가로:

- 시드 실패 시 로그 레벨을 올리거나, `ENVIRONMENT=prod` + 빈 words 조합이면 기동 실패로 처리하는 것을 검토한다
- `test_seed.py`가 이미지 레이아웃과 무관하게 데이터셋을 찾도록 정리한다
