📝 현재 문제점
---

- 랭킹 상위에 명백한 치트 기록이 존재한다 (`score = 2,147,483,647` (INT32 max) / `combo = 2,147,483,647` 등 2건). #72에서 상한 검증이 추가되어 신규 치트 입력은 차단되었으나, **기존 치트 기록을 정리할 수단이 없다** — DB에 직접 접근하지 않는 한 제거 불가.
- **PIN을 잊은 플레이어를 구제할 수단이 없다** — `pin_hash`가 NULL이 아닌 한 본인 입력 외에는 풀 수 없음.
- **악성 플레이어를 차단할 수단이 없다** — 닉네임 단위 가입 차단·계정 비활성화 UI 미존재.
- 선행 spec `docs/superpowers/specs/2026-05-16-admin-page-design.md`가 작성되어 있으나 미구현 상태로 남아있다.

🛠️ 해결 방안 / 제안 기능
---

- [동적 단어 풀 + Admin 콘솔] 이슈에서 admin 콘솔의 인프라(인증, 라우팅, 화면 골격, 세션 토큰 모델)가 먼저 구축된다. 본 이슈는 그 위에 **플레이어 관리 기능**을 추가한다.
- 선행 spec `2026-05-16-admin-page-design.md`의 기능 범위를 그대로 흡수하되, 인증 모델은 신 spec(`2026-06-02-dynamic-word-pool-admin-design.md`)의 다중 admin + DB 세션 토큰 방식을 따른다.
- 기능:
  - 플레이어 목록 조회 (검색·정렬·페이지네이션)
  - 플레이어 개별 조회
  - 플레이어 기록 수정 (score / stage / combo / play_count)
  - 플레이어 비활성화 (소프트 삭제) / 활성화
  - 플레이어 영구 삭제 (하드 삭제, 강제 확인 후)
  - PIN 초기화 (`pin_hash`를 NULL로 클리어)
  - 비활성 플레이어를 랭킹·기존 조회 API에서 제외
