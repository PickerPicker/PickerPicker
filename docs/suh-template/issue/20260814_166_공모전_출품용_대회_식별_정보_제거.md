📝 현재 문제점
---

게임 공모전 출품을 앞두고 있는데, 현재 빌드에는 이전 출품 이력을 그대로 드러내는 정보가 남아 있습니다.

- 홈화면 **크레딧** 버튼 → 크레딧 화면에 `2026 INTERCON` 문구와 팀원 실명 5인이 노출됩니다.
- `README.md` 팀 소개 섹션에 `2026 INTERCON 출품작` 문구와 팀원 실명, 프로필 이미지가 있습니다.

블라인드 심사를 전제로 하는 공모전에서는 출품물이 특정 대회, 팀, 개인을 식별하게 하는 정보를 담으면 안 되는 경우가 많습니다. 현재 상태로 제출하면 심사 익명성이 깨집니다.

🛠️ 해결 방안 / 제안 기능
---

플레이 화면에서 대회, 팀 식별 정보가 보이지 않도록 정리합니다.

- 홈화면에서 크레딧 진입 버튼과 크레딧 화면 연결을 제거합니다.
- `README.md`의 대회명, 팀원 실명, 프로필 이미지 섹션을 제거합니다.
- 게임 내 다른 화면(랭킹, 명예의 전당, 통계, 튜토리얼)에 동일한 노출이 없는지 함께 확인합니다.

⚙️ 작업 내용
---

- `src/features/player/StartScreen.tsx` — 크레딧 버튼 및 화면 전환 상태 제거
- `README.md` — 팀 소개 섹션 정리
- 잔여 참조 검색 후 타입체크, 린트, 빌드 검증

**한 달 뒤 원복 예정**이므로 크레딧 화면 컴포넌트 파일 자체는 남겨둡니다. 되돌릴 때 버튼만 다시 연결하면 됩니다.

> 참고: 저장소 커밋 히스토리, `CHANGELOG.md`, 기존 이슈 제목에는 대회명이 남아 있습니다. 히스토리 재작성 없이는 제거할 수 없으므로 이번 작업 범위에서 제외합니다. 저장소를 함께 제출하지 않는 것을 전제로 합니다.
