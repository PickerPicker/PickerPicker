# ⚙️[기능추가][CI/CD] GitHub Actions에서 env 파일 시놀로지 자동 업로드 워크플로 추가

라벨: 작업전
담당자: Cassiiopeia

📝 현재 문제점
---

- GitHub Secrets에 저장된 `.env` 파일 내용이 시놀로지 NAS에 자동으로 동기화되지 않아 수동 관리 필요
- 프론트엔드(`.env`)와 백엔드(`backend/.env`) 두 개의 env 파일을 각각 관리해야 함
- 배포 시 최신 환경 변수가 서버에 반영되었는지 확인하기 어려움

🛠️ 해결 방안 / 제안 기능
---

- `PROJECT-AUTO-FILE-UPLOAD.yaml` 워크플로 신규 추가
- main 브랜치 push 시 자동 트리거
- GitHub Secrets의 env 파일 내용을 시놀로지 `/volume1/projects/pickerpicker/github_secret/` 경로에 업로드
- 프론트엔드 `.env`와 백엔드 `backend/.env` 각각 독립적으로 업로드
- 타임스탬프 백업 디렉토리 생성으로 이력 관리
- 메타데이터 JSON 파일로 업로드 이력 추적

⚙️ 작업 내용
---

- `.github/workflows/PROJECT-AUTO-FILE-UPLOAD.yaml` 신규 작성
  - FE env: `FRONTEND_ENV_FILE` Secret → `/volume1/projects/pickerpicker/github_secret/frontend/.env`
  - BE env: `BACKEND_ENV_FILE` Secret → `/volume1/projects/pickerpicker/github_secret/backend/backend.env`
- GitHub Secrets 추가 필요: `FRONTEND_ENV_FILE`, `BACKEND_ENV_FILE`

🙋‍♂️ 담당자
---

- 백엔드: 서새찬
- 프론트엔드: 서새찬
