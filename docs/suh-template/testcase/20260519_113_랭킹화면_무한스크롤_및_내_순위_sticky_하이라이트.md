## 🧪 테스트 케이스: 랭킹 화면 무한스크롤 및 내 순위 sticky 하이라이트
**이슈**: #113  **담당자**: @Cassiiopeia

---

### ✅ 1. 무한스크롤 기본 동작

- [ ] 랭킹 화면 진입 시 최초 20개 로드됨
- [ ] 스크롤을 끝까지 내리면 추가 20개 자동 로드됨
- [ ] 추가 로드 중 스피너(loading indicator)가 표시됨
- [ ] 더 이상 데이터 없을 때 "전체 N명" 문구 표시되고 추가 요청 없음
- [ ] 빠르게 연속 스크롤해도 중복 API 요청이 발생하지 않음

### ✅ 2. 내 순위 sticky 동작 (로그인 상태)

- [ ] 랭킹 진입 시 내 행이 화면에 없으면 테이블 하단에 sticky 행 표시됨
- [ ] sticky 행에 `★`, 순위, 닉네임, 점수, 스테이지, 콤보, 플레이 수 정상 표시
- [ ] 스크롤해서 내 행이 화면에 들어오면 sticky 행이 사라짐
- [ ] 내 행이 화면에 보일 때 인라인 하이라이트(보라색 왼쪽 border + 배경색) 적용됨
- [ ] 내 행이 다시 화면 밖으로 나가면 sticky가 재표시됨

### ✅ 3. 순위 연속성 확인

- [ ] 1~20위 → 21~40위 로드 시 순위 번호가 연속으로 이어짐 (21위부터 시작)
- [ ] 각 페이지 경계(20위/21위)에서 순위 중복 또는 누락 없음

### ⚠️ 4. 엣지 케이스

- [ ] **비로그인 상태**: sticky 행 없음, 랭킹 목록만 표시
- [ ] **내 닉네임이 랭킹 전체에 없는 경우**: 전체 로드 완료 후 "아직 랭킹에 없습니다" 문구 표시
- [ ] **랭킹 데이터 0건**: "아직 랭킹 데이터가 없습니다" 문구 표시
- [ ] **전체 플레이어가 20명 이하**: 첫 로드 후 "전체 N명" 표시, 추가 스크롤 요청 없음
- [ ] **내 순위가 1~20위 내**: 진입 즉시 내 행 보임 → sticky 없음, 인라인 하이라이트만

### 🎨 5. UI/UX 확인

- [ ] sticky 행 스타일이 테이블 컨테이너 너비 안에 맞게 표시됨 (전체 화면 폭 아님)
- [ ] sticky 행과 테이블 사이 구분선(보라색 border-top) 표시됨
- [ ] 헤더(thead)가 스크롤 시 상단 고정 유지됨
- [ ] 1위 금색 / 2위 은색 / 3위 동색 순위 색상 정상 표시
- [ ] 점수 콤마 포맷 정상 표시 (예: `412,500`)

### 📡 6. API 확인

- [ ] `/ranking?limit=20&offset=0` 첫 요청 정상
- [ ] `/ranking?limit=20&offset=20` 두 번째 요청 정상, rank가 21부터 시작
- [ ] Swagger(`/docs`)에서 `offset` 파라미터 노출 확인
