### TC-01: 랭킹 행 클릭 시 공개 통계 모달 표시

| 항목 | 내용 |
|------|------|
| 전제조건 | 랭킹에 데이터가 1명 이상 존재 |
| 절차 | 홈 → `랭킹` 진입 → 임의의 플레이어 행 클릭 |
| 기대 | 해당 플레이어의 공개 통계 모달이 뜨고 닉네임/최고 점수 등 표시. `✕` 또는 바깥 클릭으로 닫힘 |
| 결과 | |

### TC-02: 모달 통계 섹션 표시

| 항목 | 내용 |
|------|------|
| 전제조건 | 플레이 기록이 충분한 공개 플레이어 |
| 절차 | 랭킹 상위 플레이어 행 클릭 → 모달 스크롤 |
| 기대 | `기본 요약`(최고점/스테이지/콤보/플레이/평균/상위%), `세부 기록`(중앙값/최저/평균 스테이지/평균 콤보), `최근 활동`(7일·30일), `스테이지별 최고점` 테이블 표시 |
| 결과 | |

### TC-03: 민감정보 미노출

| 항목 | 내용 |
|------|------|
| 절차 | 공개 플레이어 모달 전체 확인 (스크롤 포함) |
| 기대 | 시간대별 플레이 습관, 세션 간격, 약점 단어(가장 어려웠던 TOP) 항목이 **표시되지 않음**. 강점 단어(잘하는/많이 만난)만 노출 |
| 결과 | |

### TC-04: 비공개 사용자 클릭

| 항목 | 내용 |
|------|------|
| 전제조건 | 통계를 비공개로 설정한 플레이어 존재 |
| 절차 | 랭킹에서 비공개 플레이어 행 클릭 |
| 기대 | "이 사용자는 통계를 비공개했습니다" 안내(자물쇠 아이콘) 표시. 닉네임·점수는 랭킹에 그대로 노출 |
| 결과 | |

### TC-05: 본인 비공개 후 본인 행 클릭

| 항목 | 내용 |
|------|------|
| 전제조건 | 로그인 상태 + 본인 통계 비공개로 설정 |
| 절차 | 랭킹에서 본인 행(★) 클릭 |
| 기대 | 본인 요약 통계가 보이며 "내 통계 (비공개 중 — 나만 볼 수 있어요)" 안내 표시 |
| 결과 | |

### TC-06: 설정 토글 노출 조건

| 항목 | 내용 |
|------|------|
| 절차 | (a) 비로그인 상태에서 `설정` 진입 → (b) 로그인 후 `설정` 진입 |
| 기대 | (a) "통계 공개" 토글 **미표시** / (b) 토글 표시. 현재 서버 저장값이 토글 상태에 반영됨 |
| 결과 | |

### TC-07: 통계 공개 기본값 ON

| 항목 | 내용 |
|------|------|
| 전제조건 | 토글을 한 번도 건드린 적 없는(또는 신규) 플레이어 |
| 절차 | 로그인 → `설정` → 통계 공개 토글 상태 확인 |
| 기대 | 토글이 켜짐(ON, 공개) 상태. 기존 플레이어 전원 기본 공개 |
| 결과 | |

### TC-08: 토글 OFF 후 타 기기 반영

| 항목 | 내용 |
|------|------|
| 전제조건 | 로그인 상태, 통계 공개 ON |
| 절차 | `설정`에서 통계 공개 토글 OFF → 다른 브라우저/시크릿 창에서 랭킹의 해당 플레이어 클릭 |
| 기대 | 토글 즉시 OFF 반영(낙관적), 서버 저장. 타 기기에서 "비공개했습니다" 표시 |
| 결과 | |
