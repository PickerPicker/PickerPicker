# 랭킹 화면 무한스크롤 및 내 순위 sticky 하이라이트

## 개요

랭킹 화면이 상위 20개만 고정 표시하던 방식에서, 스크롤 시 20개씩 자동 로드하는 무한스크롤 방식으로 전환했다. 로그인 상태일 때 내 닉네임 행을 시각적으로 강조하고, 내 순위가 뷰포트 밖에 있을 때는 테이블 하단에 sticky 고정으로 항상 확인할 수 있게 했다.

## 변경 사항

### 백엔드

- `backend/src/services/player_service.py`: `get_ranking`에 `offset` 파라미터 추가 — SQLAlchemy `.offset()` 체이닝
- `backend/src/apis/ranking_router.py`: `/ranking` 엔드포인트에 `offset` 쿼리 파라미터 추가, rank 계산 시 `offset + i + 1`로 수정하여 페이지네이션 시 순위 연속성 보장

### 프론트엔드

- `src/services/playerService.ts`: `getRanking(limit, offset)` 시그니처 변경 — offset 파라미터 추가
- `src/App.tsx`: `RankingScreen`에 `nickname` prop 전달 (기존 미전달 상태)
- `src/components/RankingScreen.tsx`: 전면 재구현

## 주요 구현 내용

**무한스크롤**: `sentinelRef` (테이블 하단 1px div)를 `IntersectionObserver`로 감시. 뷰포트 진입 시 다음 20개 로드. `offsetRef`로 현재 로드 위치 추적, `hasMore` 플래그로 중복 요청 방지.

**내 순위 sticky**: 두 번째 `IntersectionObserver`가 `myRowRef` (인라인 내 행)를 감시.
- 내 행 뷰포트 밖 → `showSticky: true` → 테이블 컨테이너 하단에 sticky 행 렌더
- 내 행 뷰포트 안 → `showSticky: false` → sticky 숨김, 인라인 하이라이트(보라색 왼쪽 border + 배경)만 표시

**엣지케이스 처리**:
- 비로그인 상태: sticky 없음
- 전체 로드 완료 후 내 닉네임이 랭킹 외: "아직 랭킹에 없습니다" 문구 표시
- 내 행 로드 전(아직 페이지네이션으로 도달 안 됨): sticky 기본 표시

## 주의사항

- 백엔드 `/ranking` API의 `limit` 기본값이 10 → 20으로 변경됨
- `GameScreen.tsx`에서 `getRanking(1)` 호출하는 부분은 기존 그대로 동작 (offset 기본값 0)
- 내 닉네임 행이 무한스크롤로 아직 로드되지 않은 구간에 있으면 sticky는 계속 표시되다가 해당 행이 로드되면 `IntersectionObserver`가 연결됨
